# OSRM veri dizini

Bu dizin büyük ve makineye özel routing dosyaları için ayrılmıştır. Gerçek dosyalar Git'e eklenmez.

OSRM servisini başlatmadan önce aynı veri köküne sahip hazırlanmış `turkey-latest.osrm*` dosyalarının burada bulunması gerekir.

Veri hazırlama komutları, seçilecek OSM bölgesi ve otobüs profili spike'ı sırasında kesinleştirilecektir.
